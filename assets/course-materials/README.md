# Course materials (enrolled learners only)

Place downloadable/printable course files here. On plugin upgrade they are
copied into protected uploads storage and registered as downloadable resources
for the matching CE course. Learners access them only through the gated
download endpoint after enrollment.

Expected Telehealth toolkit filename (DOCX or PDF):

- `CTA_Telehealth_Clinical_Resource_Toolkit_v2_0.pdf` (preferred if available)
- `CTA_Telehealth_Clinical_Resource_Toolkit_v2_0.docx`
